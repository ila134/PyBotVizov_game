# 🎴 Психологический бот "Вызов!"

Telegram-бот для проведения интерактивной психологической игры с использованием метафорических карт и психогеометрии.

## ✨ Возможности

- **🎯 Персональный запрос** - Формулировка и калибровка личного запроса пользователя
- **🎲 Интуитивный кубик** - Проверка истинности запроса с помощью случайного выбора
- **🔷 Психогеометрия** - Определение психотипа через выбор геометрических фигур
- **🃏 Метафорические карты** - Визуальные образы для работы с бессознательным
- **🤖 Интерактивное взаимодействие** - Пошаговый диалог с кнопками и медиа-контентом

## 🛠️ Технологии

- Python 3.x
- python-telegram-bot
- Requests
- SQLite (для хранения состояний)
- Метафорические карты и психогеометрические тесты

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd challenge-bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте бота:
- Получите токен бота у [BotFather](https://t.me/BotFather)
- Замените `TOKEN` в коде на ваш токен
- Подготовьте изображения для карт и фигур

## 🚀 Запуск

```bash
python bot.py
```

## 🎮 Как играть

1. **Начало** - Отправьте команду `/start` или нажмите "НАЧАТЬ ИГРУ"
2. **Формулировка запроса** - Опишите свой вопрос или проблему
3. **Калибровка** - Проверьте истинность запроса с помощью кубика интуиции
4. **Психогеометрия** - Выберите две геометрические фигуры
5. **Метафорические карты** - Вытягивайте карты для получения insights
6. **Завершение** - Получите персональные рекомендации

## ⚙️ Настройка

### Токен бота
Замените значение переменной `TOKEN` на ваш токен:
```python
TOKEN = "ваш_токен_здесь"
```

### Изображения
Разместите в папке с ботом:
- 5 изображений для психогеометрии (`психогеометрия-изображения-1.jpg` до `5.jpg`)
- 52 метафорические карты (`метафорические карты вызов-изображения-1.jpg` до `52.jpg`)

## 🔧 Команды

- `/start` - Начать игру
- `/cancel` - Прервать текущую сессию
- "🎯 НАЧАТЬ ИГРУ" - Начать новую игровую сессию
- "🎴 Вытянуть карту" - Получить метафорическую карту
- "🤔 Помощь в интерпретации" - Получить помощь с толкованием карты

## 📊 Состояния бота

Бот использует систему состояний для управления диалогом:
- `START` - Начальное состояние
- `STAGE1` - Формулировка запроса
- `STAGE2` - Калибровка кубиком
- `STAGE3` - Психогеометрия
- `STAGE4` - Работа с картами
- `COMPLETED` - Завершение игры
